# Update Column in Pandas

This program demonstrates how to update the values of an entire column in a Pandas DataFrame.

## Concept Covered

* Updating an entire column
* Performing calculations on existing column values

## Example

The employee salary is increased by 50% using:

```python
df['Salary'] = df['Salary'] * 1.5
```

This updates the salary value of every employee.

## Learning

Pandas allows us to perform operations on an entire column without using a traditional loop.

This is useful for data cleaning, transformation, and analysis.
